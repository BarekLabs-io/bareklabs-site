# Clean Code & TypeScript Guard

* Strict Typing: No loose `any` types. Define clear interfaces or types for all data structures, props, and API responses.
* Component Modularity: Keep UI components small, single-purpose, and cleanly separated from data-fetching or layout logic.
* Tailwind discipline: Use utility classes cleanly without redundant nesting or messy inline styles. Ensure fully responsive layouts (mobile-first approach).
* Self-contained fixes: When modifying a file, ensure all imports, exports, and dependencies remain intact and fully functional.
